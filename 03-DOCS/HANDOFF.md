## 2. The goal

Replace a slow manual process for building **"Areas We Serve" pages** (one page for every Service x Location combination, for example 8 services x 10 cities = 80 pages) with **one WordPress plugin** that does everything with as few clicks as possible, works on any client site, and keeps each site's data separate.

### The old manual process (what the plugin replaces)

1. Install the ACF plugin, import `inputs/acf-export-2025-12-20.json` (field group "Locations", post type `areas-we-serve`, taxonomy `location`).
2. Install the WP Ultimate CSV Importer Pro plugin.
3. Upload client images to the Media Library, copy their URLs.
4. Paste business name, services, keywords, locations, phone numbers and image URLs into a fixed ChatGPT prompt (`inputs/seo-team-chatgpt-prompt.txt`) to get a CSV.
5. Import the CSV into the "Areas We Serve" post type.
6. In Divi > Theme Builder, add a template for "All Areas We Serve", import `inputs/SCO Layout.json`, adjust branding (fonts, colors, buttons) to match the site.
7. Edit any single page later through its ACF fields in the WordPress editor.

## 3. What the plugin does now (v1.9.0)

Menu: **WordPress admin > SEO Boster**. It is built from modules; each module is a card on the SEO Boster dashboard and can be turned on or off.

### Module A: Keyword Adder (v1.0.0)
Paste keywords. The plugin scores every page (title, URL, Yoast or Rank Math focus keyphrase, page text, synonyms such as corp = corporation, LLC = limited liability company, WY = Wyoming), picks the best page per keyword, writes a natural sentence containing it, lets you review or change everything, then adds the lines to the pages (rendered through `the_content`, the page's own content is never rewritten). Report shows page, line number, exact text, and a direct link to the line (`page-url#seob-line-3`). Undo per keyword or per run. CSV export.

### Module B: Area Pages (v1.1.0 to v1.9.0)

How a page is made: for each Service x Location, the plugin asks the AI for one JSON object with all text fields (rules from the team's prompt are in the system prompt), checks it (word counts, location in headings, title case, banned words "professional/reliable/expert" in section 2 heading, repeated sentences, meta length), asks again only for serious problems (max 2 AI calls per page), then fills fixed fields in code (post title "{Service} in {Location}", page heading "Best {Service} in {Location}", phone as `tel:+1XXXXXXXXXX`, contact link, images by the team's image rules, alt tags), saves all ACF fields, Yoast and Rank Math title, description and focus keyword, Location term, featured image. FAQ schema (FAQPage JSON-LD) is added on every Area page.
